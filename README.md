> **Vision-Up 최종 발표 / 2026**

## 📌 프로젝트 개요 (Overview)

본 프로젝트는 비디오 영상을 기반으로 사실적인 사운드를 합성하는 Video-to-Audio(V2A) 분야에서, 물체의 시각적 움직임뿐만 아니라 실제 물리적 충돌 역학(Inertia, Mass, Material)을 정밀하게 반영하기 위한 연구입니다.

기존 V2A 모델(MMAudio 등)의 2D 픽셀 기반 모션 추론 한계와, 선행 연구 PAVAS(CVPR 2026)의 VLM 텍스트 상식 질의 의존성 및 3D 체적 폐기 문제를 극복하기 위해, **3D 기하 점군 적분($V$), 표면 광학 물성 기반 유효 밀도($\rho_{\text{eff}}$), 내부 충실도 계수($\alpha$)**에 기반한 **결정론적 질량 산출 엔진($m = \alpha \cdot \rho_{\text{eff}} \cdot V$)**을 제안하고 **Phy-Adapter** 모듈을 통해 Flow Matching DiT 백본에 통합했습니다.

## 🔬 핵심 연구 내용 및 기여 (Key Contributions)

### 1. 선행 연구(PAVAS CVPR 2026)의 2대 한계 규명 및 극복
- **VLM 블랙박스 텍스트 의존 탈피**: 외형이 유사한 쇠구슬과 유리구슬(밀도 3.14배 차이)이나 속이 빈 알루미늄 캔의 질량을 VLM 텍스트 질의(Qwen2.5-VL)로 추론하던 불투명성을 폐지하고, 물리 방정식 기반 결정론적 연산으로 대체.
- **폐기되던 3D 기하 정보의 부활**: 속도($v$) 추출 후 버려지던 CUT3R 3D 점군을 SAM 2 객체 마스크와 역투영하여 3차원 볼록 껍질(Convex Hull) 체적으로 적분.

### 2. 결정론적 질량 산출 공식
$$m = \alpha \cdot \rho_{\text{eff}} \cdot V$$

1. **체적 적분 ($V$, $\text{m}^3$)**:
   - CUT3R 3D 점군 + Open3D 볼록 껍질(Convex Hull) 알고리즘으로 원근 왜곡 없는 절대 부피 산출
2. **유효 밀도 ($\rho_{\text{eff}}$, $\text{kg/m}^3$)**:
   - 비전 재질 분류기(MINC/ViT)의 반사광·텍스처 분류 확률 벡터와 표준 물리 밀도의 가중합
   $$\rho_{\text{eff}} = \sum_{k} (p_k \cdot \rho_k)$$
3. **내부 충실도 ($\alpha$, $0.0 \sim 1.0$)**:
   - 용기형 물체 감지 시 표면적($S$)과 두께($t$) 기반 박막 껍질 모델 적용
   - 충돌 관측 시 반발 탄성 계수($e$) 감쇠율로 충실도 역산, 정적 물체는 $\alpha=1.0$ 폴백

### 3. Phy-Adapter 통합 및 특징 정규화 파이프라인
- 실수 질량($m$) $\to$ 로그 압축($\log(1 + m)$) $\to$ Z-Score 정규화($\frac{\tilde{m} - \mu}{\sigma}$)
- MMAudio Flow Matching DiT 백본 가중치를 동결(Freeze)한 상태에서 가벼운 Phy-Adapter 모듈을 통한 잔차 변조(Residual Modulation) 수행

### 4. 주요 정량적 성과
- **질량 추정 평균 절대 백분율 오차 (MAPE)**:
  - 기존 PAVAS VLM 질의 방식: **68.4%**
  - 단순 체적 모델 ($\alpha=1.0$ 고정): **31.2%**
  - **제안 모델 ($m = \alpha \cdot \rho_{\text{eff}} \cdot V$): 8.7% (오차 59.7%p 감소, 87.3% 개선)**
- 저음역(Bass) 에너지 오차 대폭 감소 ($10^{-3} \sim 10^2$ 질량 스케일 안정 수렴)

## 🖥️ 발표 및 실행 가이드 (Usage Guide)

### 1. 브라우저에서 실행
[index.html](file:///c:/Users/사용자/Desktop/PPT%20제작/비전업%20ver2/index.html) 파일을 Chrome, Edge 등의 모던 웹 브라우저로 엽니다.

### 2. 발표용 인터랙티브 단축키
- **`→` / `Space` / `PageDown`**: 다음 슬라이드로 이동
- **`←` / `PageUp`**: 이전 슬라이드로 이동
- **`F` Key**: 전체화면(Fullscreen) 모드 전환 / 해제
- **`B` Key**: 청중 주목용 블랙스크린(Blackout) 모드 온/오프 (클릭 시 복귀)
- **모바일/태블릿**: 좌우 터치 스와이프 지원

### 3. 11번 슬라이드 시연 영상 등록 방법
- 슬라이드 11번의 "비디오 파일 드롭 또는 클릭하여 선택" 영역에 시연 비디오(`.mp4`, `.webm`)를 드래그앤드롭하거나 클릭하여 로컬 파일을 선택하면 즉시 인라인으로 재생됩니다.

### 4. PDF 인쇄 및 저장 방법
1. 브라우저에서 `Ctrl + P`를 누릅니다.
2. 대상: **PDF로 저장 (Save as PDF)** 선택
3. 레이아웃: **가로 (Landscape)**
4. 여백: **없음 (None)**
5. 옵션: **배경 그래픽(Background graphics) 체크**
6. 저장 클릭 시 실선 깨짐이나 여백 잘림 없이 12장의 깨끗한 16:9 PDF 슬라이드로 저장됩니다.
